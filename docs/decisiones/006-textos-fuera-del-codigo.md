# 006. Textos fuera del código, ES/EN

- **Estado:** Vigente
- **Fecha:** 2026-10-28

## Contexto
Falls se explica con texto, y debe estar al menos en español e inglés.

## Decisión
Ningún texto visible para el usuario se escribe en el código. Todos van en archivos de recursos con claves, uno por idioma.

## Consecuencias
- Añadir un idioma no obliga a tocar el código.
- Las explicaciones se pueden revisar sin ser programador.

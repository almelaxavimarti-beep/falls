# 009. Licencia MIT desde el primer commit

- **Estado:** Vigente
- **Fecha:** 2026-10-28

## Contexto
Falls es gratuito y libre. Las librerías que use deben ser compatibles con eso.

## Decisión
El proyecto usa la licencia MIT desde el primer commit. Antes de añadir una librería se revisa su licencia.

## Consecuencias
- Cualquiera puede usar, modificar y redistribuir Falls.
- Quedan descartadas librerías con licencias incompatibles.

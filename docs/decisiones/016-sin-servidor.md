# 016. Sin servidor

- **Estado:** Vigente
- **Fecha:** 2026-10-29

## Contexto
Falls es gratuito para todo el mundo y no tiene ingresos fijos (solo donaciones voluntarias). Un servidor supondría gastos que crecen con cada usuario.

## Decisión
Falls se ejecuta entero en el ordenador del usuario: el análisis, el generador, el servidor MCP (v2) y el chat con IA (v3, con la clave del propio usuario). La distribución y la web usan servicios gratuitos (GitHub Releases y GitHub Pages).

## Consecuencias
- Coste mínimo: 0 € al año, o unos 10 € al año con dominio propio.
- Falls funciona sin internet.
- No hay cuentas de usuario ni sincronización en la nube. Si algún día hicieran falta, sería otra decisión.
